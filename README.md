# otto-skills

A collection of reusable [Hermes Agent](https://github.com/NousResearch/hermes-agent) skills.

## Usage

Skills are structured as standalone packages. To install a skill:

```bash
hermes skills install <skill-url>
```

Or browse the [skills catalog](https://github.com/metzjosh/otto-skills/tree/main/skills).

## Skills

| Skill | Description |
|-------|-------------|
| [tee-time](./skills/tee-time/) | Golf tee time planning with weather-first recommendations |

## Publishing

This repo follows the agent-skills registry format. Each skill lives in `skills/<skill-name>/` with a `SKILL.md` as the entry point.
